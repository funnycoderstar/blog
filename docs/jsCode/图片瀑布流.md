## 图片瀑布流布局

瀑布流布局：多列等宽，每次将新图片插入到当前高度最小的列中。

### 思路

1. 计算列数 = `Math.floor(容器宽度 / 列宽)`
2. 维护一个 `colHeights` 数组记录每列当前高度
3. 每次取高度最小的列，将图片插入该列，更新该列高度

### 纯 JS 实现

```html
<style>
  #waterfall {
    position: relative;
    margin: 0 auto;
  }
  .waterfall-item {
    position: absolute;
    width: 200px;
  }
  .waterfall-item img {
    width: 100%;
    display: block;
  }
</style>

<div id="waterfall"></div>
```

```js
const COL_WIDTH = 200; // 每列宽度（px）
const GAP = 10;        // 间距（px）

function waterfall(container, items) {
  const containerWidth = container.offsetWidth;
  const colCount = Math.floor(containerWidth / (COL_WIDTH + GAP));
  const colHeights = new Array(colCount).fill(0);

  items.forEach((src) => {
    const img = new Image();
    img.src = src;

    img.onload = () => {
      // 找到高度最小的列
      const minHeight = Math.min(...colHeights);
      const colIndex = colHeights.indexOf(minHeight);

      const item = document.createElement('div');
      item.className = 'waterfall-item';
      item.style.left = colIndex * (COL_WIDTH + GAP) + 'px';
      item.style.top = minHeight + 'px';
      item.appendChild(img);
      container.appendChild(item);

      // 更新该列高度
      colHeights[colIndex] += img.height * (COL_WIDTH / img.width) + GAP;
    };
  });
}

const container = document.getElementById('waterfall');
const images = [
  'https://picsum.photos/200/300',
  'https://picsum.photos/200/150',
  'https://picsum.photos/200/250',
  'https://picsum.photos/200/400',
  'https://picsum.photos/200/200',
  'https://picsum.photos/200/350',
];
waterfall(container, images);
```

### CSS 多列布局方案（简单版）

无需 JS，利用 `column-count` 实现：

```css
.waterfall {
  column-count: 3;
  column-gap: 10px;
}
.waterfall-item {
  break-inside: avoid; /* 防止图片被截断 */
  margin-bottom: 10px;
}
.waterfall-item img {
  width: 100%;
  display: block;
}
```

> 缺点：CSS 方案是按列从上到下排列（报纸式），不是按行插入最短列，视觉顺序与数据顺序不一致。

### CSS Grid 方案

```css
.waterfall {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: masonry; /* 实验性属性，Firefox 支持 */
  gap: 10px;
}
```

> `masonry` 目前仍是实验性属性，生产环境建议使用 JS 方案。
