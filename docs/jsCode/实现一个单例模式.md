## 实现一个单例模式（Singleton Pattern）

单例模式保证一个类只有一个实例，并提供一个全局访问点。

### 思路

用一个变量标记是否已创建过实例，若已创建则直接返回该实例。

### 基本实现

```js
class Singleton {
  constructor(name) {
    this.name = name;
  }

  static getInstance(name) {
    if (!Singleton._instance) {
      Singleton._instance = new Singleton(name);
    }
    return Singleton._instance;
  }
}

const a = Singleton.getInstance('a');
const b = Singleton.getInstance('b');

console.log(a === b); // true
console.log(a.name);  // 'a'
```

### 通用惰性单例（闭包实现）

将"单例逻辑"与"业务逻辑"分离，可复用于任意类：

```js
function singleton(fn) {
  let instance = null;
  return function (...args) {
    if (!instance) {
      instance = fn.apply(this, args);
    }
    return instance;
  };
}

// Usage: 创建全局唯一的弹窗
function createModal(content) {
  const div = document.createElement('div');
  div.innerHTML = content;
  document.body.appendChild(div);
  return div;
}

const createSingleModal = singleton(createModal);

const modal1 = createSingleModal('Hello');
const modal2 = createSingleModal('World');

console.log(modal1 === modal2); // true，只创建了一次
```

### 应用场景

- 全局状态管理（如 Vuex store、Redux store）
- 全局唯一弹窗 / Toast
- 浏览器中的 `window` 对象
- Node.js 中数据库连接池
