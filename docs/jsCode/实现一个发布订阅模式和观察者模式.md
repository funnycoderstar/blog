# 实现发布订阅模式和观察者模式

## 区别

| | 观察者模式 | 发布订阅模式 |
|---|---|---|
| 耦合度 | 观察者和被观察者直接依赖 | 通过事件中心解耦，互不认识 |
| 通信方式 | 被观察者主动通知观察者 | 发布者触发事件，订阅者响应事件 |

---

## 观察者模式（Observer Pattern）

被观察者（Subject）维护一个观察者列表，状态变化时主动通知所有观察者。

```js
class Subject {
  constructor() {
    this.observers = [];
  }

  subscribe(observer) {
    this.observers.push(observer);
  }

  unsubscribe(observer) {
    this.observers = this.observers.filter((ob) => ob !== observer);
  }

  notify(data) {
    this.observers.forEach((observer) => observer.update(data));
  }
}

class Observer {
  constructor(name) {
    this.name = name;
  }

  update(data) {
    console.log(`${this.name} received:`, data);
  }
}

// Usage
const subject = new Subject();

const ob1 = new Observer('Observer 1');
const ob2 = new Observer('Observer 2');

subject.subscribe(ob1);
subject.subscribe(ob2);

subject.notify('state changed'); // Observer 1 received: state changed
                                 // Observer 2 received: state changed

subject.unsubscribe(ob1);
subject.notify('second update'); // Observer 2 received: second update
```

## 发布订阅模式（Publish-Subscribe Pattern）

通过一个事件中心（EventEmitter）进行解耦，发布者和订阅者互不感知。

```js
class EventEmitter {
  constructor() {
    this.events = {};
  }

  on(event, listener) {
    if (!this.events[event]) {
      this.events[event] = [];
    }
    this.events[event].push(listener);
    return this;
  }

  once(event, listener) {
    const wrapper = (...args) => {
      listener(...args);
      this.off(event, wrapper);
    };
    // Keep a reference to the original listener for off() to work
    wrapper._original = listener;
    return this.on(event, wrapper);
  }

  off(event, listener) {
    if (!this.events[event]) return this;
    this.events[event] = this.events[event].filter(
      (l) => l !== listener && l._original !== listener
    );
    return this;
  }

  emit(event, ...args) {
    if (!this.events[event]) return this;
    this.events[event].forEach((listener) => listener(...args));
    return this;
  }
}

// Usage
const emitter = new EventEmitter();

const handler = (msg) => console.log('on:', msg);
emitter.on('message', handler);

emitter.once('message', (msg) => console.log('once:', msg));

emitter.emit('message', 'hello');
// on: hello
// once: hello

emitter.emit('message', 'world');
// on: world   (once handler is already removed)

emitter.off('message', handler);
emitter.emit('message', 'silent'); // nothing logged
```
